Лабораторная работа №5
Основы JavaScript в браузере

Дисциплина: «Языки и технология программирования».
Вариант №20, повышенный уровень. Мини-приложение «Расходы».
Регион: Алматы, Казахстан. Валюта: казахстанский тенге (KZT, ₸).

1. Тема и цель

Переменные, условия, циклы, функции, события и работа с DOM. Цель — научиться получать данные из HTML-элементов, проверять ввод и динамически изменять страницу средствами JavaScript.

2. Условие варианта

Добавление названия и суммы расхода, динамический список, общая сумма и удаление записей.

3. Запуск

Распаковать архив целиком и открыть index.html в современном браузере. Установка и интернет не требуются. Ввести название и положительную сумму в тенге, затем нажать «Добавить расход». Для удаления нажать «Удалить» рядом с записью.

4. Алгоритм

  1. Получить элементы страницы через querySelector. Загрузить сохранённый массив расходов.
  2. При событии submit отменить перезагрузку через preventDefault и прочитать value полей.
  3. Проверить название и сумму: от 0,01 до 100 000 000 ₸, не более двух десятичных знаков. Разрешены точка и запятая. Ошибку вывести рядом с формой.
  4. Добавить объект с названием и суммой в массив. Суммы хранить целыми числами в тиынах, чтобы избежать ошибок округления.
  5. Функцией renderExpenses пройти массив циклом for, создать li, span и button через createElement, вычислить итог и обновить DOM.
  6. При click удалить выбранную запись методом splice, сохранить массив и обновить страницу. При input убрать старое сообщение об ошибке.

Используются const и let, if/else, цикл for, пользовательские функции, события submit, click и input, textContent, classList.add, replaceChildren и append. Название выводится через textContent, поэтому введённая HTML-разметка не выполняется.

5. Дополнительная функция

Автоматическое сохранение массива в localStorage и восстановление при открытии страницы. Это решает проблему потери списка после перезагрузки или закрытия вкладки. Данные хранятся только в данном браузере и не передаются на сервер. Если сохранение заблокировано, приложение продолжает работать и показывает предупреждение. Для файлов, открываемых напрямую, доступность localStorage зависит от настроек браузера; проверка выполнена в Microsoft Edge.

script.js

"use strict";

const STORAGE_KEY = "lab5-almaty-expenses-v1";
const form = document.querySelector("#expense-form");
const nameInput = document.querySelector("#name");
const amountInput = document.querySelector("#amount");
const list = document.querySelector("#expense-list");
const error = document.querySelector("#error");
const currency = new Intl.NumberFormat("ru-KZ", { style: "currency", currency: "KZT", maximumFractionDigits: 2 });
let expenses = [];

// Деньги хранятся в тиынах (целые числа), чтобы не накапливать ошибки округления.
function parseAmount(value) {
  const normalized = value.trim().replace(",", ".");
  if (!/^\d+(?:\.\d{1,2})?$/.test(normalized)) return null;
  const [whole, fraction = ""] = normalized.split(".");
  const amount = Number(whole) * 100 + Number(fraction.padEnd(2, "0"));
  if (!Number.isSafeInteger(amount) || amount <= 0 || amount > 10000000000) return null;
  return amount;
}

function saveExpenses() {
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(expenses));
  } catch {
    document.querySelector("#storage-note").textContent = "Сохранение недоступно. Записи сохранятся только до закрытия страницы.";
  }
}

function loadExpenses() {
  try {
    const saved = JSON.parse(localStorage.getItem(STORAGE_KEY) || "[]");
    if (Array.isArray(saved)) {
      expenses = saved.filter(item => item && typeof item.name === "string" && item.name.trim().length > 0 && item.name.length <= 80 && Number.isSafeInteger(item.amount) && item.amount > 0 && item.amount <= 10000000000);
      if (!Number.isSafeInteger(expenses.reduce((sum, item) => sum + item.amount, 0))) expenses = [];
    }
  } catch {
    document.querySelector("#storage-note").textContent = "Сохранённые записи недоступны. Можно добавлять новые расходы.";
  }
}

function renderExpenses() {
  list.replaceChildren();
  let total = 0;
  // Цикл создаёт элементы DOM и одновременно вычисляет общую сумму.
  for (let i = 0; i < expenses.length; i++) {
    const expense = expenses[i];
    total += expense.amount;
    const row = document.createElement("li");
    row.classList.add("expense-row");
    const number = document.createElement("span");
    number.className = "number";
    number.textContent = `${i + 1}.`;
    const name = document.createElement("span");
    name.className = "expense-name";
    name.textContent = expense.name;
    const amount = document.createElement("span");
    amount.className = "expense-amount";
    amount.textContent = currency.format(expense.amount / 100);
    const button = document.createElement("button");
    button.type = "button";
    button.className = "delete";
    button.dataset.index = String(i);
    button.textContent = "Удалить";
    button.setAttribute("aria-label", `Удалить расход: ${expense.name}`);
    row.append(number, name, amount, button);
    list.append(row);
  }
  document.querySelector("#total").textContent = currency.format(total / 100);
  document.querySelector("#count").textContent = String(expenses.length);
  document.querySelector("#empty").hidden = expenses.length > 0;
}

form.addEventListener("submit", event => {
  event.preventDefault();
  const name = nameInput.value.trim();
  const amount = parseAmount(amountInput.value);
  nameInput.setAttribute("aria-invalid", String(!name || name.length > 80));
  amountInput.setAttribute("aria-invalid", String(amount === null));
  if (!name || name.length > 80) {
    error.textContent = "Введите название расхода (до 80 символов).";
    nameInput.focus();
  } else if (amount === null) {
    error.textContent = "Введите сумму от 0,01 до 100 000 000 ₸, не более двух знаков после запятой.";
    amountInput.focus();
  } else if (!Number.isSafeInteger(expenses.reduce((sum, item) => sum + item.amount, 0) + amount)) {
    error.textContent = "Общая сумма слишком велика. Удалите часть записей.";
  } else {
    expenses.push({ name, amount });
    saveExpenses();
    renderExpenses();
    form.reset();
    error.textContent = "";
    document.querySelector("#status").textContent = `Добавлен расход: ${name}.`;
    nameInput.focus();
  }
});

list.addEventListener("click", event => {
  const button = event.target.closest("button[data-index]");
  if (!button) return;
  const index = Number(button.dataset.index);
  const removed = expenses.splice(index, 1)[0];
  saveExpenses();
  renderExpenses();
  document.querySelector("#status").textContent = `Удалён расход: ${removed.name}.`;
  const nextButton = list.querySelectorAll("button")[Math.min(index, expenses.length - 1)];
  if (nextButton) nextButton.focus();
  else nameInput.focus();
});

form.addEventListener("input", event => {
  error.textContent = "";
  event.target.removeAttribute("aria-invalid");
});

loadExpenses();
renderExpenses();

9. Вывод

Создано приложение для учёта расходов в тенге. Освоены обработка событий, проверка пользовательского ввода, работа с массивами, создание и удаление DOM-элементов. Реализованы подсчёт общей суммы и сохранение данных между сеансами.

10. Краткие ответы для защиты

  • JavaScript обеспечивает поведение и интерактивность страницы.
  • let позволяет переназначить переменную; const запрещает переназначение, но не изменение содержимого массива или объекта.
  • if/else выбирает ветвь выполнения по условию.
  • Циклы: for, while, do…while, for…of, for…in.
  • Функция — именованный или анонимный блок действий; параметр принимает входное значение.
  • DOM — представление документа как дерева объектов.
  • Элемент получают через getElementById или querySelector.
  • textContent — текст узла; value — текущее значение поля ввода.
  • Событие — сигнал о действии пользователя или браузера; addEventListener подключает обработчик.
  • Классы меняют через classList.add, remove и toggle.
  • Элементы создают через createElement и вставляют через append.
  • Массив перебирают циклом for или for…of.
  • Проверка ввода предотвращает неверные расчёты и некорректное состояние программы.
  • Разделение HTML и JavaScript упрощает чтение, поддержку и повторное использование кода.
