# ЛР №12, вариант 1 (базовый уровень) — Личный кабинет студента

Вход по логину и паролю, сообщения об ошибках, выход с подтверждением.
Сессия хранится на сервере, браузер получает только её номер в cookie `HttpOnly; SameSite=Strict`.

## Запуск

Windows: дважды щёлкнуть `start.bat`. Или в терминале:

```bash
npm install        # один раз
npm start          # сервер на http://localhost:3000, сессия 5 минут
npm run start:short   # сессия 30 секунд — показать истечение сессии
npm test           # автотесты 8 сценариев
```

## Тестовые учётные записи

`student1` (Алексей Тестов) и `student2` (Дана Тестова). Данные вымышленные.
Пароли в репозитории не хранятся — в `data/users.json` только соль и хеш scrypt.

## Структура

```
server.js          сервер: вход, выход, сессии, проверка доступа
data/users.json    тестовые студенты (хеши паролей, оценки)
public/index.html  разметка
public/style.css   стили
public/app.js      клиентская логика
test/auth.test.js  автотесты
```

## API

| Метод и адрес           | Ответы                                         |
|-------------------------|------------------------------------------------|
| `POST /api/login`       | 200 вход, 400 пустые поля, 401 неверные данные |
| `POST /api/logout`      | 200, сессия удалена                            |
| `GET /api/me`           | 200 свой кабинет, 401 без входа или истекла    |
| `GET /api/students/:id` | 200 свой, 403 чужой кабинет, 401               |
