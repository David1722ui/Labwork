# ЛР №12, вариант 9 — Сервис задач

Вход в систему, список личных задач, запрет просмотра чужих задач.
Сессия хранится на сервере, браузер получает только случайный идентификатор в cookie `HttpOnly; SameSite=Strict`.

## Что нужно

- Node.js версии 18 или новее (https://nodejs.org, вариант LTS).

## Запуск

Windows: дважды щёлкнуть `start.bat`. Или в терминале:

```bash
npm install        # один раз: установить Express
npm start          # запустить сервер (сессия 5 минут)
```

Открыть в браузере: http://localhost:3000

Для демонстрации истечения сессии можно запустить сервер с сессией 30 секунд:

```bash
npm run start:short
```

Остановить сервер: `Ctrl + C` в окне терминала.

## Автотесты

```bash
npm test
```

Проверяются все 8 обязательных сценариев из методички (вход, неверный пароль, пустые поля,
доступ без входа, выход, истекшая сессия, чужой ресурс, обновление страницы).

## Тестовые учётные записи

| Логин      | Имя            | Задачи     |
|------------|----------------|------------|
| `student1` | Алексей Тестов | №1, №2, №3 |
| `student2` | Дана Тестова   | №4, №5     |

Пароли в репозитории не хранятся (п. 5 требований). В `data/users.json` лежат только соль и хеш scrypt.
Чтобы задать свой пароль: `npm run hash`, ввести пароль и вставить полученные `salt` и `hash`
в запись пользователя в `data/users.json`.

Все данные вымышленные, реальных персональных данных нет.

## Структура

```
server.js            сервер: маршруты, проверка сессии, права доступа
src/auth.js          хеширование паролей, хранилище сессий, разбор cookie
src/store.js         загрузка пользователей и задач
data/users.json      тестовые пользователи (только хеши паролей)
data/tasks.json      начальные задачи
public/index.html    разметка
public/style.css     стили
public/app.js        клиентская логика (вход, выход, задачи, таймер сессии)
test/auth.test.js    автотесты 8 сценариев
tools/hash-password.js  получение хеша для нового пароля
```

## API

| Метод и адрес          | Доступ        | Ответы                                   |
|------------------------|---------------|------------------------------------------|
| `POST /api/login`      | все           | 200 вход, 400 пустые поля, 401 неверные данные |
| `POST /api/logout`     | все           | 200, сессия уничтожена, cookie удалена   |
| `GET /api/me`          | после входа   | 200 профиль и остаток сессии, 401        |
| `GET /api/tasks`       | после входа   | 200 только свои задачи, 401              |
| `GET /api/tasks/:id`   | владелец      | 200, 401, 403 чужая, 404 нет такой       |
| `POST /api/tasks`      | после входа   | 201 создана, 400, 401                    |
| `PATCH /api/tasks/:id` | владелец      | 200, 400, 401, 403, 404                  |
